# AVSAR Diagnostic Assessment (Assessment Visits & Student Assessment Reports)

## What is AVSAR?
AVSAR stands for **Assessment Visits & Student Assessment Reports**. It is TheMentR's proprietary at-home diagnostic evaluation designed to assess a student's learning profile before tutor matching and curriculum planning.

### Purpose and Philosophy
- **"Education Must Start With An Assessment"**: Rather than placing a tutor blindly based only on class and subject, AVSAR evaluates how the student actually learns.
- **Root Cause Diagnosis**: Identifies whether difficulty in school stems from conceptual gaps, study habits, exam anxiety, or mismatch with previous teaching styles.
- **Personalized Roadmap**: Provides data-driven insights to customize the mentor's teaching pace and strategy.

### Structure of an AVSAR Assessment Visit
- **Duration**: 60 to 90 minutes.
- **Location**: Conducted in the student's home for maximum comfort.
- **Dimensions Evaluated**:
  1. **Subject Familiarity & Foundational Knowledge**: Checking prerequisite concepts in core subjects (Math, Science, Languages).
  2. **Learning Style Mapping**: Determining whether the student learns best through visual, hands-on/practical, or auditory explanations.
  3. **Cognitive & Problem-Solving Approach**: Assessing how the student tackles unfamiliar problems and handles mistakes.
  4. **Academic Goals & Timelines**: Understanding upcoming school exam schedules, target scores, and parent expectations.

### AVSAR Report & Next Steps
- Following the visit, parents receive a comprehensive Student Assessment Report summarizing key observations and recommending a customized study frequency.
- TheMentR uses the report to select the educator whose pedagogical strengths best match the student's learning profile.
